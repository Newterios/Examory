# Offline face-presence baseline

Install the two pinned packages with `python -m pip install -r ml/proctoring/requirements.txt`. Run `python -m ml.proctoring.detect --video /private/session.avi --consent /private/record.json --output /private/observations.json`. The program checks affirmative recording authorization and an exact SHA-256 match before opening a local video with OpenCV. The manifest supplies `webcam_consent`, `video_sha256`, an opaque `exam_session_id`, and the v1 `context` with course, group and session IDs. A study custodian must verify the participant's permission for this use. A manifest is an assertion from that custodian.

The baseline samples the frontal-face cascade every 200 ms in recording time. Zero detections produce an `absent` interval and two or more produce `multiple_faces`. One-face interruptions up to 500 ms between identical states are bridged. Segments shorter than 1,000 ms are discarded. The final frame's duration is estimated from the video frame rate. The output contains recording-relative half-open intervals and their duration share. An empty interval list produces a null risk. Only a human reviewer can interpret an observation. Lighting, exposure, profile views, occlusion and camera placement can all affect counts.

The FR-52 fixture is in `fixtures/risk.proctoring.v1.json`. Run `python -m unittest ml.proctoring.test_detect` for a two-second blank video decoded by the real capture path and tests covering merged gaps and multiple-face intervals. No consented participant clips accompanied this task. Participant-level accuracy remains unmeasured. No video, face crops or biometric identifiers are stored in the repository.

For a consented, manually annotated sample, prepare a private JSON array. Each element supplies a local `video` path, its `consent` manifest path and an `annotations` list of `{from_ms, to_ms, kind}` objects relative to recording start. Run `python -m ml.proctoring.evaluate --index /private/clips.json --report aggregate.json`. The table is micro-averaged by milliseconds per state. A metric with a zero denominator is null.
